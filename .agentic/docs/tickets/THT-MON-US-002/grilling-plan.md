# Grilling Plan — THT-MON-US-002: Sign-Out Flow

> Generated by a `/grilling` session (grill-with-docs) against user story
> `THT-MON-US-002` (As a Supervisor I want to sign out of the call monitoring dashboard).
>
> This document captures every decision from the interview, the ADRs, the
> glossary, and the concrete implementation plan. The synthesized spec lives
> alongside this file as `to-spec.md`.

---

## 1. Summary

A complete, secure sign-out mechanism for the supervisor call-monitoring dashboard.
The flow includes backend audit logging via `POST /api/auth/logout`, client-side token & state destruction (Pinia store + `localStorage`), TanStack Query cache clearing (`queryClient.clear()`), Axios 401 response interception for auto-signout on expired/invalid tokens, and post-signout notification banners on the login view.

## 3. Architecture Decision Records

### ADR-001: Backend Logout Endpoint (`POST /api/auth/logout`)

**Status:** Accepted

**Context:** While JWT is inherently stateless on the client, security best practices and system auditing require recording user logout events on the backend.

**Decision:** Create a `POST /api/auth/logout` endpoint in Spring Boot requiring Bearer token authentication:
- Returns `200 OK` with payload `{"message": "Logged out successfully"}`.
- Logs a security audit log event (`User '<username>' logged out`).

---

### ADR-002: Vue Query Cache Purge & Pinia Auth Reset

**Status:** Accepted

**Context:** When a user logs out, cached call records in TanStack Vue Query memory could potentially be accessed if another user uses the same browser session.

**Decision:**
- In `useAuthStore.logout()`, clear `token` and `username` from state and `localStorage`.
- Call `queryClient.clear()` (via TanStack Query `useQueryClient` or imported `queryClient` instance) during sign-out execution to completely flush cached query results.

---

### ADR-003: Axios Response Interceptor for 401 Auto-Signout

**Status:** Accepted

**Context:** Expired JWT tokens or invalid credentials resulting in `401 Unauthorized` API responses should cleanly degrade to the login screen without leaving the application in a broken/half-authenticated UI state.

**Decision:**
- Configure Axios response interceptors in `services/api.js`.
- Upon catching a 401 error, invoke `authStore.logout()`, purge query cache, and redirect to `/login?expired=true`.

---

### ADR-004: Post-Signout Feedback via Route Query Params

**Status:** Accepted

**Context:** Users need visual confirmation that sign-out succeeded, or context if they were force-signed-out due to session expiry.

**Decision:**
- Route navigation to `/login` passes query parameter `?signedOut=true` or `?expired=true`.
- `LoginView.vue` detects query parameters and displays a success alert (`"You have been successfully signed out."`) or warning alert (`"Your session has expired. Please log in again."`).

## 4. Glossary

| Term | Definition |
|---|---|
| **Sign-Out Flow** | The end-to-end user and system sequence executed when a supervisor logs out or session expires. |
| **Token Destruction** | Removing JWT token strings from both memory (Pinia store) and persistent storage (`localStorage`). |
| **Query Cache Flush** | Executing `queryClient.clear()` to strip all cached API responses from browser RAM. |
| **401 Interceptor** | Middleware in Axios that catches HTTP 401 responses and triggers automatic session cleanup and redirection. |

## 5. Implementation Plan

### Phase 1: Backend Logout Endpoint (`backend/`)
1. Update `AuthController.java` with `@PostMapping("/logout")`.
2. Update `SecurityConfig.java` to ensure `/api/auth/logout` is authenticated with Bearer token.
3. Write backend unit tests in `AuthControllerTest.java` for logout endpoint.

### Phase 2: Frontend Auth Store & Services (`frontend/`)
1. Update `services/api.js` with Axios response interceptor for 401 errors.
2. Update `stores/auth.js` to call `POST /api/auth/logout` and clear state/localStorage.
3. Integrate `queryClient.clear()` into the sign-out composable/action.

### Phase 3: Frontend Views & Navigation (`frontend/`)
1. Update `MonitoringView.vue` sign-out handler to invoke logout and navigate to `/login?signedOut=true`.
2. Update `LoginView.vue` to check route query parameters and display feedback alert messages.
3. Add unit tests for `useAuthStore.logout()`, Axios interceptor, and `LoginView` alert handling.
4. Add Playwright E2E test verifying complete sign-out flow.
